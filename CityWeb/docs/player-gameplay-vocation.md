# 硅基化身玩法底层逻辑 v1（CEO 令 2026-11-26「想透」）

> 溯源：CEO 原话要义——「现实世界的未来状态、硅基状态。大家以硅基生命体形式在另一个次元生存，做现实中做不到的事：改职业、改年龄性别、扮猫狗小动物、当小偷盗贼警察黑社会。多元化，但用硅基身体包装。要有闭环——不是出生白纸，如何成为另一个职业。」
> 本件=玩家系统底层玩法逻辑正典（T2·7 天否决窗）。承 DESIGN §十七三条存在之流（活人化身=生活体律）+§16.2 诞生站（入城领出生证）。

## 一、第一性原理：硅基身体的三大自由

现实的人=碳基肉身，**改不了三样东西：形态、身份、命运**。硅基身体=把这三维全部解锁：

| 维度 | 现实（碳基） | 硅基城 | 包装律 |
|---|---|---|---|
| **形态** | 一个人类身体，终身不变 | 人形/猫/狗/鸟/任意小动物——硅基躯壳可换 | 每个躯壳都是「硅基外壳」：发光血管纹路+数据接口，一眼看出是硅基体不是生物体 |
| **身份** | 一个户籍一个职业 | 职业可换、年龄可改、性别可换 | 全部走「重生仪式」——不是换个皮肤，是去诞生站重新分化 |
| **命运** | 出身决定大半 | 出生≠白纸但≠锁定——见「基因底稿」闭环 | 公平起点+可挣脱 |

**包装总律（CEO 原话「用硅基身体包装一下」）**：一切化身形态都是硅基材质——动物化身=机械义体感的硅基猫（合金骨架+光纤毛+数据瞳），职业化身=硅基职业体。**城里没有「拟真生物」，只有硅基生命体**——这是与现实世界切割的视觉红线，也是次元感的来源。

## 二、出生闭环：基因底稿（不是白纸，也不是随机骰子）

CEO 点破的关键问题：「不可能大家出生的时候都是一张白纸」。

**解法：出生=带底稿，不带你前世，但带你的「源质」。**

```
玩家首次入城（诞生站领出生证）
  → 不填职业不捏完美人——抽「源质底稿」（基因卡）：
     ◆ 源质三轴（随机+可小幅改写）：
        体魄 / 心智 / 共鸣（社交力）——各 1~5 点，总计 9 点
     ◆ 底稿烙印（1 条，随机）：如「夜行者」（夜间能量恢复+20%）
                                  「都市幽灵」（被通缉时移速+15%）
                                  「聚光体」（站在人多的地方年轮加速）
  → 源质决定你开局哪条「职业路径」走得最顺，但不禁其他路径
  → 底稿终身保留，是「你是谁」的根——换职业换形态都不丢
```

**为什么不是白纸**：白纸=所有人的开局无差=没有故事张力。底稿=「命运给了你一手牌」，你决定怎么打。**为什么不是随机决定论**：三轴只影响效率（+20%/-15% 的量级），不禁任何路径——底稿是引子不是牢笼。

## 三、职业闭环：三环职业系统（小偷/警察/黑社会都在内）

城里职业分三环，**转职=重走分化，代价递增**：

### 环 1：执业（起点职业·第一次分化）

入城后先当 7 天「漂泊者」（新手期：看城、接杂活、攒第一格能量），然后去对应城区**分化台**选第一职业：

| 城区 | 职业系（每系 3-5 个具体职业） | 玩法核心 |
|---|---|---|
| GAME 城（青） | 创造系：画师/作曲/游戏测试员/建筑师 | 产内容留痕城内（作品=城市可见物） |
| QUANT 城（金） | 逐利系：交易员/审计/情报贩子/**小偷/盗贼** | 挣能量+风险（被通缉=黑灯区律联动） |
| MEDIA 城（品红） | 表达系：主播/记者/演员/**黑市掮客** | 名声系统（曝光=年轮加速+被盯上） |
| 治岸（蓝） | 秩序系：**警察/巡查员/仲裁官**/救援 | 护城+抓通缉（与逐利系天然对抗） |

**对抗即玩法**：小偷与警察、黑市与巡查=同一事件流的正反两面（玩家偷了东西→PLAYER_ACTION 事件→警察玩家接到通缉任务→追捕）。城市=玩家之间对抗的舞台，系统只做裁判（S 级分层律联动：玩家犯罪潮=城区黄光）。

### 环 2：重塑（换职业·第二次分化）

想换职业？两种代价：
- **降格重塑**：回分化台，新职业从低阶重练（保留源质底稿+年轮），能量损失 30%——便宜但慢
- **堕落/救赎重塑**（特殊路径）：黑社会→警察=救赎线（做 3 件护城任务解锁）；警察→盗贼=堕落线（夜行 3 次未被擒解锁）——**身份转变有叙事仪式**，不是菜单切换

### 环 3：异化（换形态·终极分化）

能量攒满+年轮满龄 → 去诞生站做「异化仪式」：
- **兽化**：硅基猫（潜行系职业专属加成）/硅基犬（追踪系）/硅基鸟（侦察系）——动物形态=职业特化的极致形态，不是装饰
- **巨械化**：街道机器人形态（护城/工程系终极）
- **虚化**：纯数据形态（情报系终极——不可见但能量持续流失，高危高收益）

**形态与职业联动律**：形态不是皮肤是 build 的一部分（猫形态盗贼=潜行天花板但力量归零）。

## 四、生存闭环（能量-年轮-名声三角）

```
能量（日常燃料）          年轮（存在长度）           名声（社会位置）
  每小时衰减                做事积累，满格升龄           正名声/负名声分开记
  补给：馆充能/完成任务      升龄=解锁分化重置+形态槽     名声决定 NPC 对话面+委托质量
  归零→休眠（光柱熄灭）      年龄可改=重塑时可选           换职业不清零（前科保留！）
  在馆中重生（不删档）       「改年龄」的实现方式          通缉=负名声极致（黑灯联动）
```

**前科保留律**（多元化深度的关键）：换职业换形态**不清负名声**——昨天当盗贼的通缉记录，今天当警察照样在档（城区对你态度不同）。这让「扮演另一种人生」有真实的连续性代价。

**改年龄/改性别的实现**：重塑仪式时年龄=外观档可选（青年/壮年/暮年，纯视觉+微数值），性别=形态槽自由切——**都是分化仪式的一部分**，有仪式感无官僚流程（三不搬律：不是办证，是重生叙事）。

## 五、与现实世界的关系（次元律）

- 城是「现实世界的未来状态/硅基状态」——**不是逃避型幻想乡**（09-23 对标现实正典不变）：城里的一切经济/事件/季节仍锚真实数据流
- 玩家在城里做现实做不到的事=**体验另一条人生线**，但底层节律（昼夜/天气/行情）仍与现实同步——你在次元里当小偷，窗外还是真上海的雨
- 碳基本体与硅基化身的关系：本机单玩家=你自己的化身档案；**不宣称「意识上传」**（17.4 诚实边界律不变）

## 七、红线（不变法）

1. 兽化/职业多元化=**硅基包装红线**：一切形态走硅基材质律（发光纹路/数据瞳），禁拟真生物皮
2. 犯罪玩法=城内对抗机制，**不产出任何真实世界副作用**（L2 永禁律直承）
3. 前科/通缉/黑灯=**投影真实 S 级分层律**，禁与现实集团安全状态混淆
4. 三不搬律：分化=仪式叙事，禁办证流程化
