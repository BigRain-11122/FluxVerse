## 三轮定谳范式（FAIL → 改案 → 复判·禁静默留）

- r157 湿路反湿条：首焙硬矩形边+周期网格感判负 → v2 边缘渐隐+行带软化仍判负（等距周期竖纹=滚动摩尔纹根）→ **v3 hash 去规律化+横带全清+边淡出 5px 合格**。
- r151 立面皮锚预演：近黑底 FAIL（dusk tint 下棕调）→ 紫移 v1 仍 FAIL → 根因定谳（tint α0.22 硬底律）→ 皮面自带锚族基值终判 PASS。
- 台架判读双读法：**4× 全 alpha 台架 + 1x 低 alpha 实尺寸**（等距周期纹理在台架读作网格、滚动相机下成摩尔纹——单读法必漏）；合成 1px 拼图接触表（r136/r150 contact sheet）供多模态逐件判。

## 多模态验图读法纪律

- 12px 像素字 OCR 误读族：以载荷断言为准（r27 律）——先机械 census 后读面，读面与机械证冲突时机械定谳。
- 采样区换算：GDI 读盘上 PNG y=0=顶 vs Unity 纹理 y=0=图底——两式必须镜像翻转（r160 首报「窗灯不可见」系采样错位非渲染病）。
- 视觉误读复核项定谳模式：像素 run 手算逐位对（r149 橙篷「宽白条」=6px 均匀 pitch 14+1 条 89=14×6+5 逐位合）。
