## 〇、城市定义（正典句）

**超体宇宙城——数字生命栖居的现实链接元宇宙：城因现实而活，现实因城而治。**

## 一、愿景三定律（CEO 同窗三令·一切设计之根）

1. **对标现实律**：城的骨架=真实上海地理（白玉兰广场=脑塔·陆家嘴=子公司集群·黄浦江=三流数据道），血肉=真实实况，皮相=赛博未来高清像素。逃避型元宇宙已死（对标幻想故死），现实型独此一家（对标现实故活）。
2. **数字生命律**：城=双物种栖息地——硅基原生民（AI 机队，真实劳动升维为生物：具名居所/真实节律/一生履历）+碳基化身（CEO 神格位塔顶光点+人格位 Jason 数字人/人设居民/访客）。**无假 NPC**：一切生命现象真实锚定。
3. **现实链接律**：三环闭环（现实入城 L0 / 城市令行 L1 签收分级 / 现实回响）。**住在城里=经营现实**——这是与 OASIS 的根本分岔：那边入城=逃离现实，这边入城=握住现实。
   - **核心推论**：数字生命的「生活」与「现实链接」是同一件事——硅基生活=真实劳动的投影，碳基行动=现实变更的通道。

### 地形规划规格 v1（CEO 令 2026-09-23「地形规划参考陆家嘴和北外滩，中间有个黄浦江」·M1 施工面·DevLoop 直接消费）

1. **总构图**：黄浦江带纵贯画面中轴偏斜（呼应真实河道弯曲），两岸对望——北岸=虹口北外滩（脑塔岸），南岸=陆家嘴半岛（三司岸）。
2. **比例基准**：江带宽≈画面 12-15%（够光流仪式与倒影演出）；北岸地块≈45%，南岸≈40%，余量=江岸留白呼吸感。
3. **北岸（治理岸·白玉兰）**：白玉兰脑塔=岸上唯一制高点（花苞塔身+塔顶纯白 CEO 光+蓝晕）；塔脚=脑环广场（信使集散+访客留言墙）；沿江历史立面群=外环感知网络+机器人站（层高克制）；西南角=光桥节点（外白渡桥意象·跨江入口）。**北岸天际线低伏**——真实虹口保护天际同构：治理谦逊，一塔独明。
4. **南岸（业务岸·陆家嘴）**：三城品字布位——上海中心扭塔（QUANT·资金金）居中制高；明珠双球（MEDIA·流量品红）滨水迎江；方塔群（GAME·数据青）后列成阵。**南岸天际线簇拥拔高**——真实陆家嘴三件套节奏：业务繁荣，群峰竞发。
5. **江面（三流数据道）**：水面=镜面反射（目标图三技法之一·倒影翻转贴图+2D 水面序列帧）；江中=数据光流（commit 光点自南岸过江回流北岸脑塔）；跨江光桥×2-3（数据桥=建筑钻取/内景窗的跨江导航隐喻）。
6. **地形取舍律（诚实边界）**：取**意象神韵+地标可辨**，不做精确测绘——赛博转译非 GIS 复刻（防规模膨胀：真实环岛/匝道/绿地只取轮廓节奏，不做街道级还原）。
7. **验收标准**：上海人一眼认出「白玉兰对望陆家嘴」；非上海人一眼读出「一岸是大脑，一岸是四肢，江是血流」。
8. **2D 实现注记**：正交相机+Tilemap 高度分带表现两岸高差；岸线用微曲线（禁直上直下=地图感）；北低南高轮廓对照即完成叙事。

## 八、红线清单（架构级·不可让渡）

1. **全 2D**：禁一切 3D（模型/场景/相机）——降维即战略（二向箔叙事）。
2. **零服务器**：禁常驻服务器；本机轮询公开 API 合规；实时多人走平台托管后路。
3. **禁装饰动画**：一切视觉表现必须对应真实事件——无假 NPC、无假作息、无伪造彩蛋。
4. **诚实律**：能力宣称=行为真实锚定的数字投影，非意识上传；引用科学神话=致敬式隐喻声明。
5. **泄密红线**：策略细节/私库细节/盈亏绝对值/机队拓扑/密钥永不出城；参观面独立脱敏文件。
6. **真金永禁全自动**：L2 执行级永留门禁链+签收。
7. **静默律**：一切计划任务 VBS 静默包装，零弹窗。
8. **同仓单执行体**：多窗退避；轮首脏只定向 add。
