## 一、生长律（为什么这样长，不另起炉灶）

城是活的超体。它的生长只遵循四条母律：

1. **行为即生命**：任何画面 = 一次真实 AI 行为/现实数据。零装饰动画。
2. **先登记后发生**：新事件类型必须先进 `schema/events-registry.json`，探针不得私产。
3. **分级才安全**：只读进城（L0）→ 城内提案 → CEO 签收才出城（L1）→ 真金永不全自动（L2）。
4. **可判定才算完成**：每阶段都有机器能验的 exit criteria，不靠"看着像"。

## 三、分阶段路线

### M1 骨架（2D 工程 + 底座修复）
- **目标**：团结引擎 1.10.3 原生 2D 工程起；脑塔+三城静态场景；感知器修到不流沙。
- **事件映射**：现有 COMMIT/HEARTBEAT/CEO_ORDER。
- **执行分级**：L0。
- **治理接口**：P0（探针修复）+ P1（引擎工程须 CEO 署名开工）。
- **完成判据（可机器验）**：
  1. verify 连续 24h 零 FAIL；
  2. tick 单实例锁生效（不重叠）；
  3. CEO 令源覆盖 docs/orders.md + BigStream/orders（见五-2）；
  4. MEDIA 城 status 由数据推断，不再写死；
  5. 引擎场景能从 world-state.json 拉起脑塔+三城。
- **依赖**：风格点选（M0）。

### M2 实况（三城活起来）
- **目标**：事件→动画映射表全部实体化（DESIGN §七 13 行逐行落地）。
- **事件映射**：13 行映射 = commit 信使 / 任务认领机器人 / OS 呼吸灯 / 写代码光砖 / 回测 K 线屏 / 进化轮脉冲 / CEO 光脉冲 / 游戏楼点灯 / 信号塔波纹 / 机队入场退场 / 开线封顶 / 互传光带。
- **执行分级**：L0。
- **完成判据**：造一条假 COMMIT → 城内 3s 内出现信使奔脑塔；心跳停 → 机器人 20min 内熄灯。
- **依赖**：M1。

### M3 驾驶舱（看 → 查 → 令）
- **目标**：L0 总览直播；下钻 L1 城区内景（三公司现有面板升维）；L2 任一实体=事件流+编年史回放。CEO 四输入面游戏化操作：方向变更=主干道改向 / P1 署名=脑塔签名光效 / 红线裁决=晶片裁决动画 / 资源调配=拖拽机器人入区。
- **事件映射**：新增 `CEO_ACTION`（签收取证）——一切令落台账，留痕可审计。
- **执行分级**：界面是游戏的，法还是法；操作本身 L0，落令触发下游 L1。
- **治理接口**：P1（操作 UI 框架）；CEO 四输入面定义见 governance §4。
- **完成判据**：点城内"发令"→ 台账出现对应 O- 令牌 + 塔顶光脉冲；编年史可拖到任意旧 commit 重放。

### M4 参观（脱敏 + 对外端）
- **目标**：tourist 视角独立 state 文件（不是引擎内开关）；微信小游戏双构建目标；公开层只放脱敏字段。
- **事件映射**：复用，零新增；字段级过滤。
- **执行分级**：L0（只读公开）。
- **脱敏红线（reality-link §四 八条，硬约束）**：策略细节/私仓原文/真实盈亏金额/粉丝精确值/机队拓扑/密钥/内部思考原文——永不出城。盈亏只给百分比与趋势色。
- **完成判据**：从 tourist 文件里 grep 不到绝对金额、commit 原文、IP/路径、密钥。

### M5 现实孪生（12 通道进城）
- **目标**：现实数据成为城的天光/巨屏/车流。TOP5 先行（clock/weather/market+calendar/fx/github_events），其余按台账排期。
- **事件映射（新增，先登记）**：`CLOCK_DUSKDAWN` `MARKET_OPEN` `MARKET_CLOSE` `WEATHER_SHIFT` `FX_TICK` `GITHUB_ECO_EVENT`。
- **执行分级**：L0（全部单向入城）。
- **完成判据**：上海真实天气变雨 → 城内天空盒出雨粒子；交易日 09:30 → QUANT 城开市钟声+K线屏常亮；休市半暗。
- **依赖**：M2（否则进城无视觉件）。
- **红线**：免费非商用源仅供对内驾驶舱；参观端商用引流须重评条款（reality-link 注3）。

### M6 闭环执行（L1 签收关卡实体化）
- **目标**：城内 AI 产提案 → 塔顶"待签收"光点 → CEO 点按才出城 → 执行结果作为新事件回流。
- **事件映射**：新增 `PROPOSE`（提案入塔）/ `CEO_SIGN`（签收）/ `ACT_RESULT`（回流）。
- **执行分级**：L1（对外有真实效果，如发公众号/视频号、交易指令生成）；真金最终执行永留 BigMoney 既有门禁链，L2 红线不破。
- **治理接口**：T2（新事件登记+7天否决窗）；"城市永不新增绕过门禁链的真金通道"写进红线。
- **完成判据**：城内发一条"发布 BigStream 内容"提案 → 未签收时台账滞留、无任何对外动作；签收后 → 走 BigStream 既有发布工具 → CONTENT_PUBLISH 事件回流、信号塔波纹。

### M7 城市自生长
- **目标**：城自己发现"新数据源/新机/新线"→ 提新探针提案 → 进化轮（周日 09:17）裁决 → 自动开工。
- **事件映射**：新增 `CITY_PROBE_PROPOSE`；复用 EVOLUTION_PROPOSE/EVOLUTION_LAW。
- **执行分级**：T2（新探针=AI 落地+否决窗）；新城区脚手架=对应新线开线令。
- **完成判据**：fleet 加一台新机器 → 城内自动识别（mtime/心跳）→ 提案"新机器人入列"→ 裁决后空降入列、灯亮。

### M8 Phygital / 城市日报
- **目标**：出城 QR（信号塔/游戏码立牌）；每周日 09:17 生成静态"城市日报"HTML 卡；真实成交/发布进城成钟声+粒子。
- **事件映射**：复用；日报=静态产物非事件。
- **执行分级**：QR/日报=L0；对外引流=M4 脱敏通过后。
- **完成判据**：周日 09:17 后本机出现当周日报卡；扫城门口 QR 直达真实产品。
