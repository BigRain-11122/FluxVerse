## 一 产品定位与玩家动线（Steam 思路）

1. **定位**：硅基城市从「工程」升格「可发布 PC 产品」——Steam 游戏思路的元宇宙城市（逛+看+点，先不做经营重玩法）。
2. **玩家动线**：双击 exe → 启动画面 → 主菜单（继续 / 进入城市 / 设置 / 退出）→ 载入 → 城市俯瞰首帧 → 自由逛（俯视缩放/平移）→ 点建筑/居民出卡 → 设置菜单随时可达。
3. **首启黄金 30 秒（判据）**：从双击 exe 到「看见活城市首帧」≤30s（含载入）；首帧必须含：城市全景+居民在动+日夜灯在呼吸。判据帧随每包呈报。
4. **设置菜单三件**（O-023 §④）：分辨率（4K/2K/1K+检测推荐）、画质档（高中低预设）、音量（总/音乐/音效）。

## 二 渲染标准：4K 母版 + 2K/1K 自适应

1. **母版律**：一切场景、资产、灯光、相机参数按 **3840×2160** 制作——4K 是母版不是可选项；2K/1K 只做降档适配，禁反向（先做 1K 再放大）。
2. **三档定义**（标杆=Cities: Skylines I 设置面）：

| 档位 | 分辨率 | 用途 | UI |
|---|---|---|---|
| 标准 | 4K 3840×2160 | 母版/旗舰机 | 100% |
| 均衡 | 2K 2560×1440 | 主流机 | 随档缩放 |
| 轻量 | 1K 1920×1080 | 底线机 | 随档缩放 |

3. **自适应**：启动检测当前屏幕分辨率→默认档推荐+手选覆盖；UI scale 随档联动（禁拉伸模糊）；全屏/窗口化两态。
4. **zoom 两端 4K 观感判据**（O-024）：近端极限=细节构图成立（不穿模不糊面）；远端极限=全景成立（LOD 不破相、街区轮廓可读）。两端判据帧预注册进五闸。

## 三 主视角与相机（O-024 执法面）

1. 主视角=**WoW 式上帝俯视角**（高机位斜俯·pitch 锁定区间）；世界维持 3D polygon 正典不变。
2. **禁自由 3D 相机**：自由飞行/任意 orbit/第一人称一律不做；设置面不提供自由相机档。
3. zoom=有限推进区间（WoW 手感）；Phase 0 三档实拍（b6b0a17）=现行基线输入，与俯视角三档参数族合流定稿。
4. HUD/选择框/框选交互随视角适配（2D 控件面见 §四）。

## 四 2D 控件界面体系（HUD/菜单/面板）

1. **范围**：主菜单 / 设置菜单（§一.4 三件）/ 城内 HUD（时间·天气·FPS 显示·位置签）/ 点击面板（建筑卡·居民卡）/ Toast 提示条。
2. **供件链**（集团产能复用律）：Biggame 2D 控件产线以**承建合同**面向城市供件（U285 界面资产律 + U288 五闸 + U331 音频标准）；互赋能不违 O-020「各做各的」定谳。
3. **制作律**：控件按 4K 设计基准铸 + 档位缩放；safeArea/CanvasScaler（ScaleWithScreenSize）/GraphicRaycaster 全过 U184 共病清单——编辑器绿≠真机绿，真包内过点验。
4. 文案/字体：本地化字体链走真机 CJK 子集律（P01/P02 范式），禁 legacy 字体豆腐。

## 六 性能档与判据（预注册）

1. **判据锚**：Phase 0 帧率读数=全档基线；此后每包硬门=帧率读数随包呈报。
2. **反面教材**：Cities: Skylines II（88,271 评 Mixed·性能口碑塌方）——性能档禁拖到 M4 之后才做，**M2 起每包必带三档帧率读数**。
3. 目标带（预注册·Phase 0 基线落地后定谳具体数值）：4K 档=中端独显可玩下限；2K 档=主流流畅线；1K 档=核显底线机不炸。首启加载 ≤30s（§一.3）。
4. 性能预算面：城市规模（街区数/居民数/粒子）与档位联动——扩量前先过帧率门。

1. **分工**：bm-a=City3D 引擎执行（实跑地+meta 生产权）；bm-c=规格/路线/验收判据/台账（本件）；Biggame=2D 控件供件；委员会=里程碑对账。
