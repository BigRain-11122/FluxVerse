# FluxVerse 美术风格正典 v1.0
> 溯源：CEO 2026-09-24 令「未来赛博，但又贴近现实，必须是2D俯视角高清像素风」
> 定位：DevLoop 美术生产唯一正典·每件素材过此闸

## 一、一句话风格

**2D 俯视角高清像素·轻赛博未来·上海滨江夜景感——像《极乐迪斯科》的港、像《Blade Runner 2049》的光、像《上海》本身的楼。**

## 二、视角与渲染

- **视角**：正交俯视角（斜 45° 等距感），非透视 3D
- **分辨率**：tile=16px 基础单元；建筑立面用 hi-bit 高密度（720p 级逻辑分辨率的小像素密度）
- **铁律**：全 2D，禁一切 3D 模型/透视相机/3D 渲染
- **参考锚点**：The Last Night / Eastward / Octopath HD-2D 的光感，但建筑本身像上海真实天际线

## 三、色调与光（核心气质）

### 日夜四档（真实北京时间驱动）
| 时段 | 主色 | 光感 |
|---|---|---|
| 晨 | 冷灰蓝+淡橙日出边 | 薄雾·窗灯渐灭 |
| 昼 | 灰白+浅青 | 干净·窗灯全灭·江面反光淡 |
| **黄昏（黄金档）** | **暖紫金+蓝紫渐变天** | **目标图气质·窗灯初亮·江面倒影最暖** |
| 夜 | 深蓝黑+冷青 | 窗灯全亮·五色律霓虹·江面倒影最暗最深 |

### 冷暖交融律
- **冷面**：科技光=超体蓝/资金金/品红/数据青（建筑霓虹/光效/数据光流）
- **暖面**：人间=窗灯暖黄/路灯橙/机器人小灯
- **纪律**：冷色管 70%（科技感），暖色管 30%（人味）——全冷=空洞，全暖=普通城市

## 四、建筑风格（贴近现实的赛博转译）

- **不做**：反乌托邦贫民窟/脏密城中村/赛博朋克脏乱差（整支排除）
- **要做**：洁净乌托邦+轻赛博——像上海陆家嘴真实写字楼加了霓虹和光效
- **建筑表情**：
  - 真实上海建筑轮廓可辨（白玉兰花苞/上海中心扭转/东方明珠双球）
  - 加赛博层=发光窗格/霓虹街牌/扫描线/大气透视雾
  - 窗灯律：规整窗格 + 20-30% 随机亮灯（零脏密·零整齐划一）
- **密度律**：稀疏新兴滨江城市——建筑不多，留白多，江面开阔

## 五、像素技法（高清感来源）

1. **小像素高密度**：不是大色块复古像素，是小像素单元拼出 hi-bit 精细立面
2. **多层光代替平涂**：每件建筑至少 3 层光（基底暗部+主色亮部+霓虹描边）
3. **hue-shift 渐变**：阴影和高光不在同色系——阴影偏蓝紫，高光偏暖金
4. **大气透视**：远楼偏蓝偏雾，近楼偏饱和——自然纵深感
5. **水面反射**：江面=建筑倒影翻转贴图+轻微波纹扰动
6. **抗平铺随机化**：同类建筑加随机变化（窗灯位置/天线/广告牌），禁重复复制粘贴

## 七、UI 壳层（操作层·世界层之外）

- 按钮/面板/内景窗框=GUIAgent 展示风（玻璃拟态+月光 LUT+柔光高级灰）
- 全部 2D 光效实现·禁 3D PBR
- 世界层保持像素风，UI 层保持玻璃拟态——两层分离

## 八、负面清单（禁入）

- 3D 模型/透视相机
- 脏乱差贫民窟风
- 卡通 Q 版/萌系
- 写实照片纹理
- 重复复制粘贴的建筑
- 全亮窗灯（=假）/全暗窗灯（=死城）
- 霓虹过载（=廉价）
