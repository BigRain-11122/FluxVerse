## 五、比例与尺寸

- **江带宽** ≈ 画面 12-15%
- **北岸地块** ≈ 45%（低伏）
- **南岸地块** ≈ 40%（簇拥）
- **岸线留白** ≈ 15%（呼吸感）
- **tile=16px**；普通建筑 2-4 tile 高；办公楼 4-6；地标 96-160px
- **角色比例**（P-17 规格落施工面正典·R-20260924-m1-visual-fix §二①）：居民 32×32 单素材系·机器人 16×16（尺度差可见）·角色:建筑 ≈1:4·门洞 ≥1.5×角色身高·招牌 ≤楼体立面高 1/2
- **相机**：全景档 Size=20（一江两岸全览）↔ 街道档 Size=9（看楼脸/机器人/内景窗）

## 六、五色律（全城光色纪律）

| 色 | 归谁 | 什么时候亮 |
|---|---|---|
| 纯白+超体蓝 | 脑塔 CEO 光 | 永远亮·全城最亮 |
| 资金金 | QUANT 扭塔 | 交易时段闪·回测演出时脉冲 |
| 流量品红 | MEDIA 双球 | 直播时亮·深夜暗 |
| 数据青 | GAME 方塔群 | 开发 commits 时脉冲 |
| 暖黄 | 人间窗灯/机器人 | 夜间点亮率=真实活跃度 |

## 七、不做的（首期边界）

- 不做：全上海还原（人民广场/徐汇/杨浦全部砍掉）
- 不做：街道级细节（匝道/环岛/地铁站内景全砍）
- 不做：精确测绘（取意象神韵·赛博转译非 GIS 复刻）
- 不做：南岸后方新城（留预留地空着·后期扩）

## 八、NPC 着地与落位律（CEO 修正令 2026-09-24）

> 溯源：ledger P-2026-09-24-69 + R-20260924-m1-visual-fix §二③（ready-to-paste 贴入·判据预注册=同件 §三——验收=实验室复扫+CEO 复验·承建自报不采信）。

- 着地三查（任一不过=禁入场景）：①精灵 pivot=脚底（非中心）②Y 贴所在地面 tile 上沿零离缝 ③带接地阴影/落点标记
- 落位白名单=人行道/广场/步行街/塔脚广场；禁=马路中央车道线/灌木绿化带/水面/楼顶
- 水面禁栽：静态物件（路灯/装饰/建筑）禁直立于水面 tile——须在岸线内或带堤墩/平台过渡；跨江仅光桥×2
- 尺度统一：居民 32×32 单素材系·机器人 16×16 尺度差可见·车辆全带轮窗
- 名牌基准统一：底边距头顶恒定 8px·紧贴归属角色
