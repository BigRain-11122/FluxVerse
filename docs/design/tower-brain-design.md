# 脑塔建筑设计规格 v2.0
> 影射：北外滩白玉兰广场（上海浦西第一高楼·楔形风帆玻璃塔）
> 定位：集团总部+超体大脑·全城唯一制高点·CEO 面壁者位
> v2 修正：去花苞文艺感→硬核赛博数据中枢

## 一、建筑形态（像素化转译）

```
        │││  ← 顶部天线阵列（三根细针·芯片引脚感）
       ╱────╲ ← 楔形切顶（斜切角·刀片感·非花苞）
      │──────│
      │██████│ ← 深色玻璃幕墙·横向数据光带
      │██████│   （每层一条细线=算力层）
      │██████│
      │██████│
      │██████│
      │██████│
      ╰──────╯ ← 数据基座（底部加宽·冷却管道外露）
```

- **总高**：全城最高（160px sprite·其余地标≤96px）
- **形态关键词**：修长矩形+楔形切顶+横向数据带——不是柔美花，是锋利的服务器刀片
- **立面**：深色玻璃（深蓝黑）+每层一条横向光带（数据管道感），窗格细密不规整
- **顶部**：三根天线针（芯片引脚），中间最粗=CEO 面壁者位
- **底部**：基座加宽一圈，外露冷却管道/数据接口（科技基建感）

## 二、塔内功能分区（从上到下）

| 层 | 功能 | 视觉表现 |
|---|---|---|
| 天线阵列 | CEO 面壁者位（神格光点）+ 三机队信号收发 | 中间针纯白常亮·两侧针随机队心跳闪 |
| 楔形切顶层 | CPH4 Labs 规划院·决策轮拍板室 | 切角边缘蓝绿光带（决策轮 00:00 闪） |
| 塔身上部 | 集团治理层·evolution 台账·夜轮 | 横向数据带暖黄流动（夜轮 03:07 全亮一下） |
| 塔身中部 | 机队算力层（硅基原生民居所=服务器机架） | 窗灯随任务亮灭·像机房指示灯 |
| 塔身下部 | 数据交换层（world-events 总线·跨江光桥入口） | 横向光带最密·数据流过感 |
| 基座 | 数据基座+冷却管道+脑环广场 | 基座外露管道+地面数据网格 |

## 三、光效演出（事件映射）

| 真实事件 | 塔上演出 |
|---|---|
| CEO 下令 | 中间天线针白光脉冲一次（全城最强） |
| 决策轮拍板 | 楔形切顶蓝绿闪三次 |
| 夜轮跑完 | 塔身横向数据带从下往上扫一遍 |
| 新居民入城 | 基座广场多一个数据光点 |
| 机队扩编 | 塔身中部多亮一排窗 |
| 全城心跳正常 | 中间天线白光常亮·呼吸灯缓慢 |
| 错误/告警 | 塔身红带横闪（E0/E1 事件） |
| 回测演出 | 塔身下部数据带金色流动（资金流过） |

## 四、日夜变化

| 时段 | 塔表现 |
|---|---|
| 晨 | 深色玻璃反射冷灰蓝·天线微亮 |
| 昼 | 玻璃反射天光·数据带暗·楔形切顶剪影锋利 |
| **黄昏** | 切顶边缘被暖紫金天映亮·数据带初亮·江面倒影最深 |
| 夜 | 中间天线纯白+蓝晕·塔身横向数据带冷暖交替·基座管道微光·全城视觉中心 |

## 五、周边（脑环广场→数据基座广场）

- 塔脚不是圆形广场，是**数据基座平台**（方形+外露管道）
- 平台=信使集散点（机器人从这里出发去全城）
- 平台边缘=访客留言墙（M4 参观端后开放）
- 地面=数据网格纹路（不是普通地砖）
- 平台沿江=滨江步道（有小机器人走）

## 六、纪律

- 全城唯一制高点——旁边建筑不得超过塔身 1/3 高度
- 中间天线白光永远最亮——任何其他建筑不得盖过
- 北岸天际线=一塔独明，其余低伏
- 塔不是装饰品=每一次光脉冲都对应真实事件（禁装饰律）
- **禁花苞/柔美/文艺感**——这是数据中枢，不是花园
