## 二 活性五面（3D 消费架构）

### 2.1 骨相活（环境节律面）——城市有物理存在感

- **昼夜**：真实北京时间主光色温曲线+环境光（R-04 已入参数单 §三.6）＋夜窗灯 emission（五色律·AD-022 Emissive_01~05 直供）。
- **窗灯律（执法）**：禁常亮装饰——街区窗灯亮度=该街区真实在场密度投影（居民在场/机器在线热力·P-38 直承）。夜城明暗分布=当日真实活动分布，看灯即看实况。
- **天气**：真实 weather 视觉（雨=粒子+湿街反射·雾=URP fog）＋**声景**=City/Assets/Audio 41 件在库按 city_phase 分时（WebGL 音频坑沿 R-02：仅 Web Audio·Autoplay 挡 BGM=开门帧交互即解）。
- **水**：InteractiveStylizedWater 流动（参数单 §三.7）——黄浦江=三流数据道正典位（数据青/资金金/流量品红五色律锚）。
- 落 Phase：**Phase 1**（装配期同步接线）；判据=窗灯分布与当日热力对账（机检：抽样街区窗灯数=数据面在场数）。

### 2.2 神经活（事件演出面）——城市对集团行为有反应

- **管线直承**（2D 定谳零改造·`R-20260928-td-craft-perf-live` B+M 双源）：10s 轮询 world-events.jsonl 只读游标增量 → 内容寻址游标去重 → 事件命令对象化（execute=演出·入时间轴队列）→ 演出播放器。直播/回放双模（编年史日档案可重放）。
- **P-41 3D 重锚表 v0**（时序参数沿 P-17；载体已按波②定谳见表后）：

| 事件 | 3D 演出（v0 初锚） | 载体 |
|---|---|---|
| CEO_ORDER | 脑塔白光脉冲 2s | emission 脉冲 |
| DECISION | 塔冠青闪/驳回橙红 | emission 色闪 |
| COMMIT | 光点自三城沿水道飞向脑塔 15-30s | 移动光点+拖尾 |
| TASK_CLAIM | 街道机器人自机库出动→目标建筑+窗灯亮 | 路径移动实例+emission |
| TASK_DONE | 机器人归位+窗灯灭 | 同上 |

| GAME_STAGE / WEATHER_ALERT | 城市情绪染色（mood_director 联动·Phase 2） | 色调层 |

- **载体定谳（波②·`R-20260928-alive3d-02`·防线二过）**：**VFX Graph 禁入 WebGL 演出面**（compute+SSBO 硬门槛·三链 A 级闭环·装机验证 SystemInfo.supportsComputeShaders==false 留证）；移动光点/光带=**Built-in ParticleSystem+Trails（World Space 拖尾·Ratio/MinVertexDistance 旋钮·Ribbon 模式可复用街带）+脚本 Transform 位移+ObjectPool 池化**（官方池示例即粒子池）；一次性脉冲 Stop Action=Callback→pool.Release 自动回收；循环待机件开 Prewarm；粒子=CPU 模拟→预算显式 Max Particles+Ring Buffer（粒子不进 SRP Batcher·性能只靠预算+Culling「when offscreen is most efficient」）；**emission 脉冲正法=少量材质实例+同 shader variant**（脑塔/地标各持独立材质·不破批）**·MPB 禁用**（URP 官方明文「likely result in a drop in performance」）；Timeline=WebGL 无平台限制记载🟡·维持脚本驱动为主·多轨复杂编排备用。
- **批量节流直承**：同窗多事件单帧 drain 合并·同型连发聚合计数（N 次 commit=一条光流加密度非 N 条）·同屏演出并发配额。
- 落 Phase：**Phase 2 主战场**；判据=逐事件演出可机检对账（演出触发时间戳 vs 事件流行号·断言零孤儿演出/零漏演）。

### 2.3 细胞活（居民投影面）——10003 居民在城里

- **核心律：居民=真实数据投影**。behavior.py 五环作息（起居/工作/社交/休闲/休息·10min 再生）导出面=引擎唯一事实源；引擎零行为逻辑。city 侧任何人形动作都是某个真实居民真实作息态的投影——禁装饰律自动满足。
- **LOD 三档绑定相机三档**（🟡 设计推断·Phase 2 判据帧微调）：

| 视档 | 居民呈现 | 数据源 |
|---|---|---|
| L0 总览 320m | 街面人口密度光尘/光点流（不显个体·城=发光生命体的宏观态） | 在场人口聚合数 |
| L1 区景 110m | 街面行人实例流（密度=真实作息窗口：早高峰/晚高峰/深夜≈0） | citizen-behavior 通勤/社交态 |
| L2 跟拍 24m | 聚光灯居民完整人形跟拍（45min 门控·台词气泡+声纹产线已备） | 年轮/台词池/声纹池 |

- **万人≠全显**（P-71 万人级上限结论直承）：业界 40 年无「万人级×运行时富模拟」先例——分层摊薄是唯一解：L0/L1=密度采样投影（真实总数缩放），L2=个体聚光灯。呈现形态待 CEO 裁（§六 A/B/C）。
- **技法定谳（波①·`R-20260928-alive3d-01`·防线二过）**：L1 行人承重=**无骨骼假动画**（位移/弹跳/朝向·A 级原语·首选）+**VAT 顶点动画**跃升档（数千级·B🟡·烘焙管线工程量·闸3 实测定谳）；**禁 Animator+SMR 群体路**（SMR 不可 instancing·A）；AnimationInstancing 判负不采（WebGL 无官方定谳）；L0 光点 <256 顶点不宜 instancing（A）→单 buffer 合批/CPU 粒子；instancing 单批 1023 上限+整组 AABB 剔除（区景档须分区批）；30fps 硬数字官方无公开=闸3 实测定谳。
- 落 Phase：L0 密度=Phase 2；L1 行人流=Phase 2；L2 聚光灯跟拍=Phase 3（栖居面）。

### 2.4 循环活（交通机器人面）——街道层流动

- **街道机器人=机队 AI 具象**（BLUEPRINT 正典「街道机器人=机队 AI」）：认领=出动/完成=归位，全由真实机队事件驱动（与 2.2 TASK_CLAIM 同源同管线）——机器人是「集团在城里的手」。
- **车辆**（AD-022 Veh×9 在库）：Phase 2 富化载体=TRANSFER 光流的物理化（数据转移=车驶过桥）；无事件无车流（禁装饰）。
- **路径技法定谳（波③·`R-20260928-alive3d-03`·防线二过）**：主技法=**waypoint 队列插值**（每实例每帧 O(1) Lerp·零依赖零 GC·8m 正交骨架天然拟合）；SplineAnimate（com.unity.splines 另装包·2.5.2 中国档·装机首验）=艺术曲线流备用；**NavMesh 判负**（既定路线数据投影⇏寻路智能——投影律直承，省烘焙省 steering）；**街带光流=移动发光条主选**（Unlit+Additive+GPU Instancing 合批·一 TRANSFER 一实例 spawn→行进→销毁）；UV 流动贴图=非事件氛围辅层；**VFX Graph 禁入 WebGL 演出面**（硬要求 compute+SSBO·WebGL2 无 compute 阶段——防线二直证 System-Requirements 页+装机验证 SystemInfo.supportsComputeShaders 兜底）。
- 判据=机器人位置与机队任务台账对账（谁出动=哪台机器认领了什么）。

### 2.5 心跳活（超体节律面）——城即生命体的仪式感
