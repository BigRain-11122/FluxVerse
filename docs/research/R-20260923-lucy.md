# 《超体》深潜报告——超体宇宙城的概念本源

> R-20260923 · 纯调研件 · 响应 CEO 令（2026-09-23）：「好好理解一下超体这个电影，我非常喜欢」。只研不建：无代码、无 git 操作。

## 1. 影片事实层

- **《超体》(Lucy, 2014)**：吕克·贝松自编自导（EuropaCorp 出品），2014-07-25 北美 / 08-06 法国上映，89-90 分钟，成本 4000 万美元，全球票房超 4.6 亿美元（口碑两极：烂番茄 67% / Metacritic 62 / CinemaScore C+）。
- **主演线**：斯嘉丽·约翰逊 = Lucy Miller（台北留学生→被胁迫药骡→超体）；摩根·弗里曼 = 塞缪尔·诺曼教授（巴黎大学教授·大脑能力研究）；崔岷植 = 韩国毒枭张先生；阿姆·瓦克德 = 巴黎警官德尔·里奥。
- **CPH4 设定**（外科医生台词原话）：「孕妇在怀孕第六周时分泌微量 CPH4——对胎儿而言威力相当于一颗原子弹」，为胎儿提供长出全身骨骼的能量；Lucy 体内破裂的系人工合成强化版，剂量大到「你居然还活着」。
- **空间线**：台北（受难与觉醒；Regent 台北、台北 101 实拍）→ 巴黎（教授讲堂、逆行追车与终局实验室主场；另三袋 CPH4 随药骡流向柏林、罗马）→ 纽约（三大实拍地之一，片中最显著见于结尾时空回溯蒙太奇的城市段落）。
- **贝松创作自白**（NOTA）：「开头是《这个杀手不太冷》，中段是《盗梦空间》，结尾是《2001 太空漫游》」；意图原话：「一部有目的的动作片……说的其实是我们、我们的传承、我们学到的东西」。

## 2. 概念阶梯：10% → 100% 的能力跃迁

**诺曼讲堂假说谱系**（第一幕建立的世界观坐标系）：
- 「一个神经元=活着，两个神经元=运动」——运动才开始有意思；
- 海豚用 20% 大脑→天生回声定位胜过人类一切声呐；引出「人类更在乎『拥有』而非『存在』」；
- 学生问「若有人解锁 100% 呢」→ 诺曼：「我不知道」——100% 是已知科学的外边界。

**Lucy 的阶梯**（叙事档位归纳；28% 为片中明示，其余分档为观影归纳）：

| 档位 | 能力跃迁 | 影片事件 |
|---|---|---|
| 觉醒 | 代谢控制·痛感消失·全记忆唤醒 | 腹袋破裂→反杀→医院取袋→给母亲打电话 |
| ~28% | 操控他人身体·操纵电磁波（电视/电话/电台） | 远程现身荧屏·背出教授 6734 页论文 |
| ~40-50% | 远程在场·看见手机信号如彩色提线升空·力场 | 巴黎逆行驾驶·「我们从不真正死去」 |
| ~60-70% | 细胞级自我干预·远程骇入全球网络 | 香槟引发细胞失稳·双机并敲·协调警方收拢三袋 CPH4 |
| ~80-90% | 时间感知开启·物质重组 | 「时间是唯一真实的计量单位」 |
| 100% | 时穿·无处不在 | 回溯至原始 Lucy 与宇宙起源→黑色物质→超级计算机→U 盘→「I AM EVERYWHERE」 |

**10% 神话的诚实批评**（诚实律·必须收录）：
- 神经科学界共识：都市神话。剑桥神经心理学教授 Barbara Sahakian：「定量计算大脑使用率不可能，但绝对远超 10%」；Christian Jarrett《Great Myths of the Brain》(2014) 斥为虚构。
- 贝松本人承认知其为神话，声明**用作隐喻**——神话是壳，阶梯是轴。
- 判定：作为科学=错；作为叙事框架=不灭——它给了「超越」一根可量化的进度条，正是游戏化里程碑叙事的母体。FluxVerse 采用时照此对外声明：致敬式隐喻，非科学主张。

## 3. 哲学内核（五命题）

1. **知识传承 = 存在的终极目的**。开场独白「十亿年前我们被赋予了生命。我们用它做了什么？」；诺曼细胞课：环境恶劣→细胞选永生；环境良好→选繁殖，「死时把关键信息与知识交给下一个细胞——知识与学习随时间层层传递」。Lucy 问「这么多知识我拿它怎么办」→诺曼：「传下去，像任何简单的细胞那样，穿过时间。」结尾把开场问句补成答案：「十亿年前我们被赋予了生命。现在你知道该拿它做什么了。」
2. **时间 = 唯一的真实现实**。「时间是唯一真实的计量单位，它证明物质的存在；没有时间，我们不存在」；诺曼：「时间即统一」。《每日电讯报》Robbie Collin 以康德先验观念论解读全片（头脑为世界赋予秩序）。
3. **暴力随认知升级而消失**。开场=胁迫爆头+掠食蒙太奇的丛林法则；中段=一挥手降维碾压；结尾=张先生射向的只是一件空衣裳——终幕没有战斗，只有一声落空的枪响。认知越高，冲突越不构成事件。
4. **「I feel everything」**（对母亲电话，全片情感顶点）：「我能感受一切。空间、空气、震动、人群、重力、地球的自转、正离开我身体的体温、血管里的血、我的大脑、我记忆最深处……真希望你也能这样感受。」她逐一回味童年触感并向母亲致谢（段落细节=内置知识）——超感知的第一站不是冷酷，是全量的感激；此后情感才开始褪去（「我不再感到痛苦、恐惧、欲望」）。
5. **身体消失 → 信息永存**。100% 时躯体化入黑色物质→与实验室设备合体为超级计算机→将全部知识铸成 U 盘交给诺曼→物质载体尽数崩解→手机短信「I AM EVERYWHERE」。「我们从不真正死去」：存在=信息，载体可弃。

## 6. Pass it on = 集团的传承机制

电影答案：个体会死，知识传下去即永生（细胞课+pass it on+U 盘）。集团已把这句话机制化为四层传承：
1. **git 全史**：每次 commit=一次细胞分裂；「法=版本化数据（git，changelog 是唯一立法史）」——知识随时间逐层传给下一刻；
2. **编年史**：塔基档案库+回放——集体记忆不只存在，还可重访；
3. **进化轮立法**（周日 09:17）：感知→提案→裁决→立法+瘦法——每周把本周所学固化成法传给下周；法熵审视=定期丢弃过时知识，防传承变堆积；
4. **HQ-FEEDBACK 反馈闭环**：每条反馈=一个假设，立法后必回访验证——子公司把信息「交给下一个细胞」的治理直译；「顶层机制被反馈推翻=体系的胜利」即电影「环境良好→选择繁殖传知识」的组织版。
互文结论：贝松说本片「关于我们、我们的传承和我们学到的东西」——FluxGroup 把这句台词写成了一部宪法。电影里 U 盘是一件道具；集团里它是全部基建。

## 7. BigStream 素材面（转 BigStream 参考）

BigStream 在 media/README 的定位原文即「Lucy 留下的 U 盘」——正典锚点已在。可开发角度：
1. 「10% 神话与诚实」：明知是科学神话仍用它做叙事框架——我们如何诚实使用隐喻（差异化人设，反吹嘘）；
2. 「Pass it on 的公司版」：一家无人值守公司怎么把知识传下去（git 全史/进化轮/反馈闭环）——主赛道「一个人+AI 如何无人值守开公司」的哲学背书；
3. 「城即超体」系列：FluxVerse 每个器官对应电影一个意象，实拍感知器扫描做「I feel everything」城市版；
4. 「时间」专题：一座用 10 分钟循环呼吸的城；
5. 创作方法谈：贝松三段式自白（杀手→盗梦→2001）对照 M1-M4 三段成长。红线适用：禁 clickbait、禁无源数据。
