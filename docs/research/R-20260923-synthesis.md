## 二、定位合并（学术×行业）

- **品类**：AI 组织驾驶舱（非元宇宙、非游戏、非 dashboard——城市隐喻解决 dashboard「建了没人看」通病，Jacobs 街道芭蕾=事件流活力的学理同构）。
- **叙事纪律（自决代决·T2·7 天否决窗）**：对外口径（含参观模式与 BigStream 素材）统一「AI 集团驾驶舱/集团操作界面」，禁用「元宇宙」一词——2026 年语义场里该词=上一个泡沫。
- **学术锚点**：Lynch 五要素=布局语言（三城=区域/脑塔=地标兼节点/主干道=路径/光门=边界）；度量即形态（CodeCity 先例：楼高=吞吐/底面积=体量/灯光=健康度）；半格而非树（三城间保留共享地带，禁画组织架构图）。

## 三、V1.5 现实链接层（本波核心交付·入册 DESIGN v3 §十五）

### 3.1 三环模型

- **环A 现实入城**（现实→城·L0 只读全自动）：真实行情/时钟/天气/汇率/生态活动/交易日历 → 城市视觉件（真K线巨屏/真实昼夜/真天气粒子/资金道流量计/外部生态脉冲）。12 通道台账见 R-reality-link §一，7 条零 key 可用。
- **环B 城市令行**（城→现实·L1 须签收）：看查令闭环+四输入面——指令文件→各 OS 循环消费→执行结果回流事件。签收关卡按 O-20260923-1620 委托令分级：总经理常签；CEO 保留四类=实盘开闸/红线增废/使命变更/重大资源承诺。
- **环C 现实回响**（现实成果→城生长）：真实成交/发布/下载→城内钟声+粒子仪式（真实事件触发，非装饰）；参观者反馈→BigStream 选题池（Block by Block 公众参与先例——「和现实互动」的参观面解法）。
