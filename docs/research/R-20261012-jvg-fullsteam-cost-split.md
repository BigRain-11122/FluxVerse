## §2 分摊结构判读（提案账期/分摊条款正身参照）
1. **市府只买「自己责任的制作段」**：€80k 不是「全项目成本」——结构=机构段封顶拨款（市府 €80k 经基金会结算）+基金会自有投入（undisclosed）+主办方商业段（Fullsteam=JVG 演出主办方·其投入走艺人与主办方的商业合同面·不在市府决策件射程）+赞助商段（PR 面在案：Marli Juissi+OnePlus·S5）——**≥4 主体分摊的免费市民场**。
2. **提案映射（10-18 提案成本分摊句直接源）**：超体宇宙城免费旗舰场合同结构候选=「底座方出数字孪生资产+机构段封顶费（€80k 量级锚）+基金会/主办方自有投入+赞助商段」——**禁「底座方全包」结构**（ZOAN 五周 crash build 的沉没成本教训=底座方以资产入股·机构段只买「城市责任的制作段」）。
3. **sole-provider 锁定位**：直购理由=底座（Virtual Helsinki 城模）唯一拥有者=一切其上活动的唯一可交付者——**「底座收租」路线的采购法面实证**（建城=拿锁定位；后续活动采购绕不开底座方·与 r378 §3 律1「模型免费钱在服务层」构成法律面+商业面双锚）。
4. **采购通道参照**：市府级虚拟活动=阈值下特别服务直购（快速·无招标）——提案「政府段」客户的合规通道成本极低（vs 招标流程）；时窗敏感型活动（节庆/突发事件替代方案）天然走此通道。
5. **金额判读边界**：€80k=**市府段封顶实数**非制作总成本（Zoan 五周 crash build 成本远超此数·差额由资产复用逻辑〔城模已建〕+基金会+商业段+赞助商吸收）——**引用禁令**：本数不得表述为「JVG 场总成本」或「ZOAN 单场收入」。
