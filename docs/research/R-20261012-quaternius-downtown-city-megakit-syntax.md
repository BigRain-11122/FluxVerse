## 4. R2 街区扩展选型位差（对 2018 件 §4 的换代评估·导入窗判据沿袭+两新闸）

- **MegaKit 优势面**：①楼体三段式堆叠语法（基座+层带×N+屋顶）=都市天际线生成器词汇——48 包/AD-022 现役面**无此楼体生长语法**（R2 街区扩展唯一新维度）；②315 件内容量=三候选池最大（vs Kenney Roads 90/2018 件 25）；③假窗内景 shader+顶点色磨损=夜景密度件工艺参考（Source 档）；④URP 2022.3.62 源工程=与我 Tuanjie 同基底（Source 档兼容位）；⑤7 预置整楼=导入即验风格样板。
- **劣势面**：①223MB 免费档=微信 30MB 总帽不可直入（City3D 部署面若走小游戏=LOD/贴图压榨必答题·桌面/Steam 面可行）；②写实倾向与 AD-022 Synty 面状同框断裂更深（三方最深）；③T/X 拓扑疑缺位沿袭；④件谱可视面比 2018 件更弱（hero 渲染非枚举格·全谱=导入窗）；⑤高架/双层语法疑弃面（立交需求仍锁 2018 件）。
- **Source 档采购面**：$14.99=资本项——按 CEO 花钱决策律（先本地验证后掏钱）+本仓零预算硬约束：**免费档先纸面+样帧验证·Source 采购决策=免费档过闸后走 HQ-FEEDBACK 呈报面**（本轮零采购动作）。
- **选型判据（导入窗执行·沿 Kenney 三闸+2018 件第四闸+新增两闸·全机械可验）**：
  1. 风格同框闸：与 AD-022 同帧渲染多模态锐评 ≥8（沿袭判据①·写实倾向加权审）；
  2. 米制定标闸：OBJ 文本直读层高/地块宽/路宽 → 对齐 AD 5.0 步距（一次定标）；
  3. 包体实证闸（**新**）：223MB 源在目标部署面（小游戏/桌面）的 LOD+贴图压缩后余量预算表——超帽=降档点缀件用法定谳（同 2018 件 T 缺位降档律）；
  4. T/X 拓扑完备闸（沿袭 2018 件判据④）：包内实名谱缺 T/X=该包不可独立承担路网词汇；
  5. **楼体堆叠完备闸（新）**：基座/层带/檐口/机房四段件实名谱齐备性=楼体生成器词汇可独立成立判据；
  6. 合批实证闸：混拼帧 drawcall 对基线非恶化（贴图集共享优势验证）。
