# ZOAN Virtual Helsinki 场单经济拆解（30+ 制作的收费主体+单场量级+公司终局）

> explore#71 领走件；母件=R-20261012-helsinki-3dplus-open-data-ecosystem.md §2C+§5 回填行#1；判据（母件 §5）=收费主体/场次收入任一实数落件——**双判据均落+公司终局实数（破产）超预期命中**。本件=活动承接提案（10-18 演化日窗三句式）的收入结构证据底座。

## §0 结论（TL;DR）
1. **收费主体=纯 B 端机构**（市府/演出主办方/美术馆/双年展/会议场馆/IP 权利方），零 C 端票务——旗舰场（JVG 五一演唱会）对市民免费、市府+Fullsteam Agency（演出主办方）买单；30+ 制作无一卖票。
2. **单场量级实数（旗舰场 2020-04-30）**：46 万台电脑在线直播+149,403 人建 avatar 入场（同屏上限 500）；观众总量=The Guardian 保守估 ~70 万（1.5 人/电脑）↔Forbes 100 万+，=芬兰史上最大线上活动、全国人口 13%。
3. **公司终局（重磅新发现）**：Zoan Oy（2010 年立·芬兰 VR 先锋·Moomin/国家博物馆/Käärijä 客户链）FY2021 营收 €3M（+60.1%）→FY2022 €5M（营业利润 ~€1M）→FY2023 €4.67M（**亏损 −€308k**）→**2024-05-14 宣告破产**（Kauppalehti 注册面 Konkurssi+Yle 报道双源）——**70 万人旗舰场救不了定制制作公司的命**。
4. **判读**：活动承接=需求验证成立（机构愿付+百万人次可达）但**商业模式判负样本**——按场次定制制作（每场新人力）=收入集中+薄毛利+单年翻车即死；ZOAN 末期自救方向（Burst 平台化+Cornerstone 自有元宇宙平台）=正确但太晚。超体宇宙城活动承接提案须以**平台/订阅经济**立项、禁以「按场接单的制作所」立项。

## §2 单场量级实数（旗舰场全数据）
- **46 万台电脑**在线观看直播；**1.5 人/电脑保守估≈70 万人**（The Guardian 口径 S2）；**149,403 人建 avatar**入场互动（同屏可见上限 500）。
- Forbes 口径=**100 万+观众**（S5）；Wikipedia 收束口径=70 万~100 万+（S3 三引注）。约=**芬兰全国人口 13%**（S4）。
- **工程面**：平台加速开发=**半年工作量压进 5 周**（S2）——活动档期驱动的能力采购（非平台常态化运营）。
- 观感口径（S2 现场记者）：技术 impressive、无 VR 头显门槛（手机/电脑即可）、但「不能说有真演唱会 buzz」——**代际判读：2020 年标杆=技术验证场，非可持续体验**。

## §4 对超体宇宙城的映射（10-18 活动承接提案配套）
1. **需求侧证据闭合**：城模上办活动=机构愿付费（市府+主办方+美术馆+IP 方六类付费主体在案）+单场 70 万人次可达（46 万直播电脑实数）——活动承接>参观导览的出口排序（r377 §0）再加一层收入结构证据。
2. **商业模式红线（本件核心增量）**：提案三句式必须写**平台经济不是制作经济**——按场次定制=ZOAN 死法（€5M 峰值营收/60 人团队/r378 S11=薄毛利制作所+单一坏年即破产）；正路=可复用活动平台（场景件复用+工具化+按场次轻制作）+**底座方收平台费/租金**（Guardian 记录的市府收租意图同向 S2）。
3. **报价锚**：机构付费承受面参照=芬兰国家级活动单场制作费量级=五周 crash 开发（人力密集可见）；我们没有 ZOAN 单场报价实数（破产文件未公开合同面·§5 回填行）——提案判据用「人次×平台费」模型，禁用「对标 ZOAN 单场制作费」。
4. **免费旗舰策略**：ZOAN 旗舰场=免费市民活动（获客成本逻辑·r378 §3 律1 同构）——超体宇宙城首场活动若办，免费+冠名/机构买单结构=已验证形态。
