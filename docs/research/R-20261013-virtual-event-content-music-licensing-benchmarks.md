## §3 红线句

**「授权义务不随承办转移」**——著作权法第三十八条把「取得著作权人许可，并支付报酬」钉在演出组织者身上，承办方（城）的义务面是平台侧审核与注意义务（r493 域），不是替主办方取得内容授权——合同把授权义务推给城=义务错位条款（城无权利人关系面·承办费模式无授权成本项=承接即亏）；配套铁律：**「直播回放是两个权项」**——实时直播落广播权、点播回放落信息网络传播权（第十条（十一）（十二）分立），报价与授权只写「直播」不写「回放」=录播窗（r488）全裸奔；归责铁律：**「成果 IP 条款是归责开关」**——斗鱼案归责链：约定直播成果 IP 归己+从直播获益=注意义务升级担责，「通知-删除」避风港不救——城约成果 IP 归城=把主办方的授权风险接到自己账上。
