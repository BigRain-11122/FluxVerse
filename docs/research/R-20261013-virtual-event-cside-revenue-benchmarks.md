## §0 缺口实证+结论
- **缺口实证**：docs/research 语料 grep「票务|票房|门票」=命中全为博物馆票务平台族（reveel-tickets 18 处/导览定价件）与瑶台计费形态侧注——**虚拟活动观众侧付费收入（票价/票房/付费直播）零专件覆盖**；「Beyond LIVE」零命中；Travis Scott 仅 2 件容量/成本件侧注（零收入面）。
- **结论一行**：C 端付费门票（付费直播平台型）单场峰值 $2.8-3.4M 但常态市场证伪（Beyond LIVE 2024 年营收 ≈ 峰值单场六成+连年净亏+资不抵债+**2026-12-19 停服**）；活态 C 端收入=**免费进场+数字衍生**（Fortnite $20M/场·线下单场纪录 ~12×）与**免费观看+品牌冠名**（视频号崔健场 4468.1 万观看·极狐独家冠名）——**本城活动收入主锚=B 端三源（政采/赞助/品牌位）·C 端付费门票禁作主收入线**。

## §1 三型收入谱
| 型 | 案例 | 单场 C 端实锚 | 终局/状态 |
|---|---|---|---|
| ① 付费直播门票 | Beyond LIVE（SM×Naver×JYP） | 峰值 ₩40 亿（~$3.37M）·12.3 万付费观众 | **死·2026-12-19 停服** |
| ② 免费进场+数字衍生 | Fortnite Astronomical（Travis Scott） | **~$20M（skins/周边带货）** | 活·平台级 |
| ③ 免费观看+品牌冠名 | 视频号崔健场（极狐独家冠名） | C 端零票费·收入=赞助（费未披露） | 活·国内主流 |

**① Beyond LIVE=付费直播平台型终局（S1 Khan fetch 直取+S3 KoreaBoo fetch 直取+S4 Wikipedia fetch 直取）**
- 世界首个全规模付费线上演唱会平台：SM×Naver 2020-04-26 首场 SuperM「Beyond the Future」**75,000+ 张虚拟票·109 国观众**；2020-08 JYP 入股成 JV Beyond Live Corporation；截至 2023-04-23 共 **91 场**。
- 票价 **₩33,000（~$27.40）=线下同档均价约 1/3**（Starnews 记者估算口径·SM 未官方披露）。
- 单场票房峰值（同口径）：Super Junior「Beyond the Super Show」**123,000 付费观众→~₩40 亿（~$3.37M）**；NCT 127「Beyond the Origin」104,000→~₩34 亿（~$2.85M）；对照线下：NCT 127「Neo City: The Origin」45 场巡演总票房 $24.4M/217,000 观众。
- **平台终局（S1·SM 2025 事业报告 2024 财年实数）**：年营收 **KRW 2,408,150,000（≈$1.75M）**=2020 峰值单场的约六成·**净亏 KRW 1,642,560,000（≈-$1.20M）·总权益 -KRW 293.9M（资不抵债）**；停服时序：TVOD 售卖止 10-23→观看止 10-30→注册/支付止 11-15→**2026-12-19 00:00 全停**。
- 判读：疫情窗口期 10 万级付费观众/场=需求存在实证·线下复演后付费意愿崩塌（**平台全年营收<峰值单场**）——付费直播门票=窗口期模式·常态市场证伪。

**② Fortnite Astronomical=免费进场+数字衍生型（S2 gamesindustry.biz fetch 直取·Forbes 源）**
- 免费进场 9 分钟虚拟演唱会（2020-04）·27.7M 独立玩家/12.3M 同接（容量面 r439 已在册·本件只补收入面）。
- 收入实锚：**gross ~$20M（含 skins/数字周边带货）**；对照线下：Astroworld 巡演**单场最高 $1.7M**·全巡演 $53.5M——**虚拟场单场=线下单场纪录 ~12×**。
- 机理：C 端收入大头**不在门票在数字衍生**（皮肤/物品经济）——需游戏级分发面+物品经济（本城衔接面=r449 品牌位/物品位族·非票务面）。

**③ 视频号线上演唱会=免费+品牌冠名型（国内主流·S5 搜索快照多源一致·快照级标注）**
- 崔健「继续撒点野」2022-04-15 视频号**首场商业化**线上演唱会·**极狐汽车独家冠名**：累计观看 **44,681,000 人次**·点赞 1.2 亿+·预约 50 万+·公域曝光 16 亿+（多源一致：百度百科/CSDN/知乎/品牌星球/搜狐）；冠名费未公开披露。
- 赞助留存信号：极狐热度后**追加冠名罗大佑场**（同主复购=赞助面留存实证）。
- 判读：国内 C 端零票费=平台默认——**收入全走 B 端品牌赞助/冠名·观测量=赞助定价锚**——与 r449 品牌广告位线同构（B 端买曝光·非 C 端买票）。

## §2 机理定谳（三型谱+P&L 归位）
- **门票型=唯一终局死型**：三型谱中唯一资不抵债停服者——票价压到线下 1/3 仍撑不起平台常态成本（对照 r414 成本件：平台租金级 $8-15k/场+制作 $35-90k/场·C 端票收常态量级≈$1.75M/年·单位经济反着乘）。
- **活型共同点=C 端不设付费墙**：Fortnite 收衍生（物品经济）·视频号收冠名（曝光经济）——C 端免费=最大到场量= B 端定价锚最大化。
- **P&L 归位（提案收入配置句正身）**：本城活动承接收入=B 端主锚三源（①政府/机构活动采购〔r421 JVG €80K 实锚〕②企业赞助/品牌冠名〔本层③型+极狐复购锚〕③城内广告位/品牌空间〔r449 Roblox 同构〕）+C 端衍生/联动位可选增量（需物品经济面·Fortnite 实证）——**C 端付费门票禁作主收入线**。
- 与 P3-003 附录 §B 红线同构：「平台经济不是制作经济」在收入面的投影=**「票房经济不是门票经济」**——收入锚在 B 端租/赞·不在 C 端票仓。

## §3 提案消费三句+判据候选（10-18 窗预置·≤3 问先立）
- **现象句**：虚拟活动 C 端直接票费已被市场证伪为常态收入线（Beyond LIVE 付费平台 2026-12 停服·2024 年营收 ≈ 峰值单场六成+资不抵债）·活态=免费进场收数字衍生（Fortnite $20M/场=线下纪录 ~12×）与免费观看收品牌冠名（视频号 4468.1 万观看·极狐独家冠名且复购）。
- **建议句**：本城活动承接收入主锚=B 端三源（活动采购+品牌冠名+城内广告位）·C 端零票费引流+衍生/品牌联动位可选增量·禁设付费门票主收入线。
- **判据候选**：
  - **J1（收入配置门）**：提案/预算正文以 C 端门票为主收入锚=判负（Beyond LIVE 停服+资不抵债双实锚）。
  - **J2（票价带门·若设付费档）**：票价锚 ≤ 线下同档 1/3（₩33K/$27.4 先例）且 C 端收入预测占比 ≤20%。
  - **J3（观模换算门）**：C 端收入估算禁用「累计观看×票价」直乘——付费观众天花板=单场 12.3 万（Super Junior 123K 峰值）·免费场 4468.1 万观看不可作付费分母。
