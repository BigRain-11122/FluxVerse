| **案件骨架**（北互 2025-09-10 发布会八案·案例五·北京日报北京号 2025-09-26 转载全文） | 基本案情 verbatim：「原告唐某某在被告某科技有限公司运营的网络平台上发布**二百多字文字内容**『打工并不能让你真的赚到多少钱，但可以开启你的新视角……如果你对学车感兴趣的话并且以后打算开车的话，可以在你最清闲的一个假期完成它……工作之后就没有太多完整的时间学驾照了』」「被告某科技有限公司运营的平台将该内容判定为**『包含AI生成内容但未标识』的违规情况，并将该内容隐藏并作出将用户禁言一天的处理**」「后原告唐某某**进行申诉未成功**」「原告唐某某主张其并未使用AI创作，被告某科技有限公司的行为违约，请求法院判令被告**撤销隐藏涉案内容和禁言账号一天的违规处理，并在后台系统中删除违规处理记录**」 | **处罚场景三要素**：①用户发布二百多字即时性短文（生活经验分享语料·零 AI 使用）②平台算法判定「AI 生成未标识」→双重处罚（隐藏内容+禁言一天）③申诉通道空转（申诉未成功=程序救济失效后诉诸司法）；**案由定谳=网络服务合同纠纷**——用户诉平台违约（非侵权）·请求=行为救济（撤销处罚+删除记录）非金钱赔偿——平台-用户纠纷的合同域入口范式 |
| **平台审查权来源**（公告=协议组成部分） | 裁判结果 verbatim：「网络用户在使用AI工具进行创作并将相关内容发布到网络平台时，**应依照诚信原则如实标记**」「被告发布社区公告要求创作者在发布包含AIGC生成的内容时，应主动使用标识，对发布时未主动声明的内容，平台将采取适当措施进行流通限制并添加相关标识；未经标签声明，使用人工智能生成的内容构成违规」「原告系平台注册用户，**上述公告属于平台服务协议的组成部分**，被告有权根据协议对用户发布内容是否属于AI生成合成内容进行审查和处理」 | **权源双面**：①用户侧诚信义务（AI 创作如实标记）②平台侧审查处理权（公告入协议→有权审查）——**社区公告/平台规则=服务协议组成部分**（公示规则即协议条款·对用户有拘束力·同时对平台自设义务标准）；审查权成立≠处罚程序豁免（权源行与说明义务行分立——有权处罚≠可以只给结论处罚） |
| **举证责任分配**（即时性创作文本例外·正主判准一） | 裁判结果 verbatim：「在一般情况下，原告应该提供如创作底稿、原件、源文件、源数据等**证明人类创作属性的初步证据**，但本案中**原告回答内容系即时性创作文本，客观上无法提供上述证据，由其提供上述证据不存在合理性和现实可行性**」 | **举证可行性律**：一般规则=用户举证人类创作属性（底稿/原件/源文件/源数据）；**例外=即时性创作文本客观不可举证**——短评/即时发言类内容天然无底稿，强令举证=不合理不可行→举证责任结构崩塌转向平台侧；城规则设计禁把「不可能提供的证据」设为用户免责前置（举证要求须按内容类型分档） |
| **平台适度说明义务**（算法掌控方=举证方·正主判准二） | 裁判结果 verbatim：「被告基于算法工具的运算结果得出涉案内容为AI生成合成的审查结论，**被告既是算法工具掌控方又是结果判断方，算法工具运算过程和审查结果由被告掌控，被告应就该事实进行合理举证或解释说明**」「虽然被告提供了算法的备案信息，但**无法确认备案信息与本案争议的关联性**」「被告**未对算法决策依据和结果进行适度的解释和说明**，未对涉案内容属于AI生成合成的判断依据和结果作出合理解释，**应对其没有事实依据的情况下对涉案账户的处理行为承担违约责任**」 | **掌控方举证律**：算法工具掌控方+结果判断方双位合一→举证/说明义务归平台（运算过程与结果皆在平台掌控内=用户无从对证）；**备案零免检**：备案信息与个案争议无关联性=零证明力（备案≠个案处罚正当性——r509 备案=上线门/本件=个案说明·两义分立锚）；**违约构成核心**=无事实依据的处理+无适度解释说明→处罚本身=违约 |
| **人工复核标准判负**（科学性判准·正主判准三） | 裁判结果 verbatim：「被告进行人工复核的标准要求**具有非常明显的人类情感特征，该判断并不具有科学依据以及较强的说服力和可信度**」 | **复核标准科学性律**：「以人类情感特征为检测标准」=法院点名不科学不可信——AI 检测的人工复核若建立在「读起来有没有人味/情感直觉」上=判负锚；复核标准须客观化（可验证指标）——AI 生成内容检测工具的复核层禁主观直觉判准 |
| **判决形态+典型意义**（行为救济+司法审查标准确立） | 裁判结果 verbatim：「法院判决被告**展开折叠的回答并删除相关后台记录**。被告不服一审判决提起上诉，后撤回上诉，一审判决生效」；典型意义 verbatim：「本案是对AI生成合成内容标识的标记、平台识别和治理在司法审查规则方面的有益探索，一方面**肯定了网络内容服务平台利用算法工具对AI生成合成内容进行审查和处理，履行信息内容管理主体责任的积极作用**；另一方面，**认定网络内容服务平台在即时性创作文本场景下对使用算法自动化决策结果承担适度说明义务，并为司法审查阶段的算法解释说明程度确立了一定的标准**。本案通过司法个案裁判，**合理分配网络内容服务平台和用户的举证责任**，推动网络内容服务平台提高算法的识别能力和决策能力」 | **判决形态=行为救济**（展开折叠+删除后台记录·无金钱判赔）——处罚记录本身=违约状态延续（删除记录=救济内容非附加）；**双向典型意义**：平台算法治理积极作用获肯定（治理权正当性面）+处罚程序义务成案（适度说明义务/举证分配/解释程度标准）——城平台治理面「有权治理·有义务说清」双面定谳 |

**谱系定谳**：城平台治理处罚面三线分立——①**处罚说明义务线**（算法掌控方=举证方·只给结论=违约）；②**复核科学性线**（主观情感特征标准判负·复核须客观可验证）；③**举证可行线**（即时性创作文本例外·举证要求按内容类型分档）；案由域=合同违约（平台-用户协议关系——与八案其余七案侵权域分立·平台责任两域：对人侵权责任〔案例八〕/对用户违约责任〔本件〕）；与既有件对位：r505=AIGC 标识域双面（生产者标识义务帽/治理者处罚义务帽——城两顶帽子分戴）；r509=说明义务三域分立升格（监管侧监督检查 19 条/用户侧处罚适度说明〔本件正主〕/算法个案解释）；r512/r513=城自运营处置记录免责面（记录=合规资产）vs 本件对用户处罚记录（记录=风险延续）——**两记录域分立**；r493=城审核义务域（对监管/内容安全）vs 本件处罚程序义务域（对被处罚用户）——审核面/处罚面分立。

## §3 消费三句+红线三句

**消费三句**（产品/工程落地面）：
1. 城对用户内容的算法处罚（隐藏/禁言/限流/信用类）通知模板必带「判定依据说明+结果说明」双字段说明段——只给结论=本案同构违约（算法掌控方=举证方：平台既控工具又判结果，说明义务在平台侧）。
2. 城人工复核与申诉复核标准禁主观直觉判准（「人类情感特征/像不像人写」类=法院点名不科学）——复核标准文档挂客观可验证指标+申诉流程含真实人工复核与说明输出（本案申诉未成功且平台判败=申诉空转实锚）。
3. 城平台规则（AI 标识要求/处置措施梯度）=服务协议组成部分——规则文本协议级严谨（公示+版本留痕·措施梯度=自设义务标准）；用户举证要求按内容类型分档（即时性创作文本=自述+场景说明替代路径·禁底稿类必填前置）。

**红线三句**（判负清单）：
1. **「算法掌控方=举证方」**——被告既是算法工具掌控方又是结果判断方→应就该事实合理举证或解释说明（verbatim 判准）——平台不能把「算法说你 AI」的证明责任推给用户；无事实依据的处罚+无适度说明=违约。
2. **「备案不是个案免检」**——备案信息与个案争议无关联性=零证明力（本案实锚）——备案=上线门/个案正当性=另案说明，两义分立禁互替。
3. **「处罚记录是违约的延续」**——法院以删除后台记录为救济（行为救济）——对用户处罚记录=风险延续面非合规资产（与 r512 自运营处置记录=免责资产两记录域分立）。

## §4 判据候选（J1-J3·机械验收）

- **J1 处罚说明义务门**：城用户处罚通知/模板档含「判定依据说明+结果说明」双字段段（档面核验；无平台处罚功能=豁免注记行——档面核验）。
- **J2 复核标准客观化门**：人工复核/申诉复核标准文档 grep「情感特征/直觉/像不像」类主观判准词=零命中+含可验证指标句（阈值/置信档/操作规程任一在案）——命中或双缺=FAIL。
- **J3 申诉可行举证门**：申诉/举证表单字段核验——「底稿/原件/源文件」类证据未设为即时类内容必填前置+「自述+场景说明」替代路径在案——必填前置在案=FAIL。

## §6 坑首录

1. **「备案=免检金牌」坑**：被告提供了算法备案信息仍判负——法院认定「无法确认备案信息与本案争议的关联性」——备案证明的是「合规上线」（r509 上线门义）不证明「本案处罚正当」（个案义）；拿备案抗辩个案=两义互替错位（城处罚文档禁写「依已备案算法处置」了事——个案说明义务独立存在）。
2. **「处罚只给结论」坑**：平台隐藏内容+禁言+「包含AI生成内容但未标识」结论标签=违约构成——缺的是「判断依据和结果的合理解释」（算法决策依据+结果说明双段）；城处罚通知模板若只有结论句+处置句两件套=本案同构（说明段是义务主体不是客服礼貌）。
3. **「主观复核标准」坑**：「人工复核的标准要求具有非常明显的人类情感特征」被法院点名「并不具有科学依据以及较强的说服力和可信度」——AI 检测复核层的「人味直觉」判准=判负锚；复核标准客观化（阈值/置信档/操作规程）是处罚正当性的组成部分（标准不科学=复核不成立=处罚无依据）。
4. **「违约与侵权混轴」坑**：本案案由=网络服务合同纠纷（违约责任非侵权责任）——平台-用户关系=协议关系：举证责任分配/义务标准/救济形态全走合同域（行为救济+记录删除·无过错侵权要件+无金钱判赔）；拿侵权案判准（过错/损害赔偿）套平台-用户处罚纠纷=错轴引用（协议义务面比侵权法面更细：公告怎么写=义务就多严——城规则文本即义务清单正主）。
