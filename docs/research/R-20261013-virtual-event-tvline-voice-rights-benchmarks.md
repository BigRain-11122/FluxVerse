## §1 基准谱：全国首例影视剧台词声音权纠纷案全解构（案情+争议焦点三问+双权项分立认定+判决形态+双专家结构）

- **案情**：游戏《西瓜摊主大战买瓜人》（被告成都睡神飞科技有限公司〔开发〕+北京睡神飞科技有限公司〔运营上架〕）使用演员孙红雷参演电视剧《征服》经典桥段（华强买瓜·「你这瓜保熟吗」网络热梗）中的**台词声音**；游戏细节（中国经营报）=地点设定天府五街·买瓜人为反派·玩家=瓜摊老板凭技能抵挡捣乱·**买瓜人形象与刘华强造型高度相似**+多句电视剧台词+道具金瓜粒子/吸铁石/生瓜蛋子=电视剧元素。原告诉称二被告未经其授权**以营利为目的**开发设计案涉游戏侵害**声音权益**+使用其人格元素塑造坏人形象侵害**一般人格权**→请求公开赔礼道歉+赔偿经济损失及精神损害抚慰金。
- **程序双时点**：开庭 2023-09-25（**合议庭争议较大→改日宣判**·微信面独有细节）·当庭宣判 2023-10-13（成都铁路运输第一法院〔成都互联网法庭〕·**「全国首例影视剧台词声音权纠纷案」头衔挂宣判日锚**）。
- **庭审争议焦点三问**（知产财经 verbatim）：①被告主张孙某作为影视剧演员「该项权利应为表演者权」——孙某**是否有权**就他人使用其影视作品主张声音权益和一般人格权侵权；②案涉游戏声音**是否具有识别性**构成声音权益侵权+人物形象是否损害一般人格权；③构成侵权时的责任承担。
- **法院认定段**（三源逐字一致 verbatim）：「自然人的声音和肖像作为标表自然人的人格标志，具有人格权属性。二被告未经孙红雷本人同意，也未取得孙红雷许可使用的影视作品著作权人授权同意，在开发、制作、运营的游戏中使用其声音，构成声音权益侵权。但游戏中人物形象设计来源于影视作品角色设定，在游戏制作中未明显偏离原剧设定。在客观表现上案涉游戏角色指向的是影视剧人物，一般公众的理性认知并未将反派形象的游戏角色识别为孙红雷本人的社会认识和评价，**基于识别指向关系的中断，不构成一般人格权侵权**。法院判决二被告向原告赔礼道歉并赔偿原告经济损失 3 万元。」
- **判准七条**：①**参照适用律**（民法典 1023 条第 2 款 verbatim「对自然人声音的保护，参照适用肖像权保护的有关规定」+1018 条第 2 款识别性要件——**声音=条件保护非绝对权**·通过特定声音可识别特定自然人时才存在保护可能性〔余俊〕）；②**营利使用双未授权即侵**（未经本人同意+未取得许可使用影视作品著作权人授权同意——双通道全断=侵权构成）；③**表演者权不吸收律**（被告「该项权利应为表演者权」抗辩判负——声音权益=**表演者单独享有的人格权益·单独行使**·与电视剧著作权归制作者〔著作权法〕分立·王飞 verbatim「可单独使用权利的相关权利人有权单独行使」）；④**双请求权并存律**（表演者声音权益+制作者视听作品著作权——同一使用行为双请求权基础不互斥·制作者「亦有权以侵害视听作品著作权为由要求停止使用声音片段」）；⑤**识别指向关系中断律**（角色层≠演员层：游戏角色指向影视剧人物刘华强·公众理性认知未将反派角色识别为孙红雷本人→一般人格权判负——**指向中断救形象救不了声音**：声音权益独立照侵）；⑥**知名度盗用定性**（余俊：知名度=市场竞争有效工具·声音=知名度媒介载体·「表面上利用的是孙红雷的声音，实际上盗用的是孙红雷的知名度」——事前授权义务〔知名自然人声音与本人联系较为特定〕）；⑦**合理范畴豁免面**（个人学习欣赏/新闻报道/依法履职等有限合理使用=豁免·**商业活动中使用不适用**——王飞）。
- **双通道授权结构**（王飞 verbatim 判读）：使用影视剧中声音片段的合规路径=**通道 A**「取得制作者授权**且**制作者通过约定获得表演者授权」（链条完整双环）或**通道 B**「与表演者签署授权协议·由表演者重新进行配音」——单一制作者授权不覆盖表演者声音（著作权链条≠人格权链条）。

## §3 消费三句+红线三句

**消费三句**（产品/工程落地面）：
1. 台词声音引用=双通道授权（制作者链完整 OR 表演者重录）——单一制作者授权不覆盖表演者声音（王飞 verbatim：电视剧著作权归制作者但声音权益=表演者单独人格权益单独行使）。
2. 可识别声音=事前授权义务（1023② 参照+1018② 识别性要件——知名自然人声音与本人联系较为特定·热梗流行度=识别性强化器）。
3. 角色层免责不及声音面（识别指向关系中断只断一般人格权——声音权益独立判定·两权项分立判读）。

**红线三句**（判负清单）：
1. **「未经本人同意的原声片段禁入城内容」**——营利使用双未授权=侵权构成（判决实锚：赔礼道歉+经济损失 3 万）。
2. **「制作者授权不等于声音授权」**——著作权链条不吸收人格权链条（表演者权抗辩判负·双请求权并存=维权通道不互斥）。
3. **「热梗不是豁免器」**——网络热梗流行度=识别性与知名度强化器（华强买瓜案本尊实锚·热梗内容越流行授权义务越重）。

## §6 坑首录

1. **宣判日/开庭日错位坑**：程序双时点分立——开庭 2023-09-25（**合议庭争议较大→改日宣判**·知产财经微信原发面独有细节）vs 当庭宣判 2023-10-13（「全国首例」头衔挂宣判日锚）；报道面两时点混用风险=引判例时间锚错位——**引判例必带双时点**（宣判日=效力锚·开庭日=程序细节锚·与 r534 坑①「时间限定词非法源限定词」家族同源：时间面措辞不作唯一锚）。
2. **请求项≠判决主文项坑**：原告诉请三件（公开赔礼道歉+经济损失+精神损害抚慰金）→判决主文只见两件（赔礼道歉+**经济损失 3 万**）——报道面「赔偿原告 3 万元」单数化易误读为全诉请支持；精确读法=精神损害抚慰金未见支持记载（判决书正身未直取·判读留痕）——**判赔数字必分项读**（诉请项/支持项/项内构成三查·与 r529 判赔 20.3 万分解〔经济损失+合理支出+精神损害〕分项法同律）。
3. **「表演者权」吸收抗辩坑（判负判读）**：被告以「演员该项权利应为表演者权」抗辩=试图以著作权邻接权体系吸收人格权益→法院以「人格标志·人格权属性+表演者单独享有单独行使」拆解——**著作权链条不吸收人格权链条**（王飞结构：电视剧著作权归制作者〔著作权法〕但声音权益=表演者单独人格权益·两链条分立）；采购侧引申=**拿到制作者授权≠拿到声音授权**（双通道判读正主·J2 门的判准基础）。
4. **识别指向关系中断=双刃剑坑**：中断（游戏角色指向刘华强非孙红雷本人）救了被告的一般人格权（反派形象诉请判负）**但救不了声音权益**——两权项独立判定·「指向中断」不能跨权项援引——城角色分派注记门判准基础（形象层低险≠声音层免检·J3 门的判准基础）；与 r527「肖像不构成/个信构成」分立判读同构（同一行为多权项分判·单一权项结论禁外推）。
